Flux d'une décision
  1. Chaque cycle (poll_interval_ms), le moteur relit les faits.
  2. Un verdict (ON/OFF + raison) en sort ; il n'est publié qu'après la durée de
     stabilité (settle_on_ms / settle_off_ms).
  3. Une commande /wake ou /sleep crée une intention : l'action part, puis les
     faits la confirment, l'escaladent ou l'abandonnent.
  4. Chaque changement est poussé à toutes les cibles de webhook_targets, puis
     répété toutes les heartbeat_seconds.

Fichiers et outils
  scripts/install.sh, scripts/uninstall.sh   installation sans sudo, migration depuis /opt
  scripts/selftest.sh, scripts/validate-live.sh   essais isolés, validation guidée
  outils/assembler-app.sh                    assemble macstatusd.app (icône, agent, build-info)
  outils/publier.sh, outils/publication.py   signature, notarisation, archive
  outils/pre-push                            garde d'anonymat avant chaque push
  config.example.json                        modèle de configuration (webhook désactivé)
